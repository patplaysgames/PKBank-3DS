# PkBank 3DS — Final Release Build Guide (.3dsx & .cia)

This package builds **both** final New Nintendo 3DS deliverables from a single C++17 codebase:
- **`PkBank3DS.3dsx`** (+ `PkBank3DS.smdh`) — Launch from **Homebrew Launcher** (`sdmc:/3ds/PkBank3DS/`)
- **`PkBank3DS.cia`** — Install directly onto the **3DS Home Menu** via **FBI** (UniqueID `0xF8A42`, New 3DS 804 MHz + L2 Cache enabled)

## Controls & Authentic Legality Features Included
- **Per-Game Official Unlock Rules**: Verifies binary save progression flags before allowing trades/transfers (Pokédex obtained in all games, Gen II Ecruteak Bill Time Capsule, FRLG Celio's Network Machine Ruby/Sapphire quest + National Dex, Emerald National Dex, Gen IV Pal Park, Gen V Poké Transfer Lab).
- **No Cheating / Backwards Transfer Protection**: Enforces sequential Gen III→IV→V→VI→VII and VC Gen I/II→VII paths; backwards transfer is not allowed.
- **New 3DS Controls**:
  - **A**: Choose / Drop / Swap (Blue cursor swaps directly)
  - **B**: Cancel / Back (prompts **Save & Exit / Don't Save / Cancel** if unsaved changes exist)
  - **X**: 3-state toggle (**Show Moves/Stats** → **Show Hidden Stats** → **Show Summary**)
  - **Y**: Cycle sharp-stylus Cursor Mode (**Red** Single → **Blue** Quick Swap → **Green** Multi-Select)
  - **L / R**: Context-aware box switching for **BANK STORAGE** or **BOX** (inactive on **PARTY**)
  - **ZL**: Manual Pokémon Cry (`ZL Cry`; auto-cries disabled)
  - **ZR**: Toggle **Validation Transfer** legality grey-out filter (also listed in **SELECT Options**)
  - **SELECT**: Options (Sort all boxes by Regional Dex No., National Dex No., Name A-Z / Z-A; ZR Validation Transfer Toggle; Release with confirmation)
  - **START**: Save Changes (atomic pre-write backup in `sdmc:/3ds/PkBank3DS/backups/`)
- **Pokémon X & Y DSP Sound Effects**: Kalos-style NDSP UI audio via `include/xy_audio.hpp`.

## Option A: Zero-Install Cloud Build (GitHub Actions) — Recommended
No local toolchain installation required:
1. Extract `PkBank3DS-n3ds-release.zip` into a new GitHub repository.
2. Push to `main` (or create a tag like `v2.0.0`).
3. Open the **Actions** tab → **Build PkBank 3DS (.3dsx + .cia)** → download **`PkBank3DS-Release`**, containing:
   - `PkBank3DS.3dsx`
   - `PkBank3DS.smdh`
   - `PkBank3DS.cia`

## Option B: One-Command Local Docker Build (Windows / macOS / Linux)
Build `.3dsx` immediately using the official devkitARM container:
```bash
docker run --rm -v "$(pwd)":/src -w /src devkitpro/devkitarm make
```

Build **both** `.3dsx` and `.cia` in one command:
```bash
docker run --rm -v "$(pwd)":/src -w /src devkitpro/devkitarm bash -c "
  apt-get update && apt-get install -y --no-install-recommends curl unzip python3 ca-certificates &&
  curl -fsSL https://github.com/Steveice10/bannertool/releases/latest/download/bannertool.zip -o /tmp/bt.zip &&
  unzip -o /tmp/bt.zip -d /tmp/bt && install -m 755 /tmp/bt/linux-x86_64/bannertool /usr/local/bin/bannertool &&
  curl -fsSL https://github.com/3DSGuy/Project_CTR/releases/download/makerom-v0.18.4/makerom-v0.18.4-ubuntu_x86_64.zip -o /tmp/mr.zip &&
  unzip -o /tmp/mr.zip -d /tmp/mr && install -m 755 /tmp/mr/makerom /usr/local/bin/makerom &&
  make release
"
```

## Option C: Native devkitPro Build
Install packages via `dkp-pacman`:
```bash
dkp-pacman -S 3ds-dev
```
Ensure `bannertool` and `makerom` are on your `PATH`, then run:
```bash
make          # builds PkBank3DS.3dsx + PkBank3DS.smdh
make cia      # builds PkBank3DS.cia
make release  # builds both into release/ with SHA256SUMS.txt
```

## Installing on Your New Nintendo 3DS

### For `.3dsx` (Homebrew Launcher)
1. Copy `PkBank3DS.3dsx` and `PkBank3DS.smdh` to:
   `sdmc:/3ds/PkBank3DS/`
2. Open **Homebrew Launcher** on your New 3DS and select **PkBank 3DS**.

### For `.cia` (Home Menu Icon)
1. Copy `PkBank3DS.cia` to `sdmc:/cias/PkBank3DS.cia`.
2. Open **FBI** on your New 3DS → **SD** → **cias** → **PkBank3DS.cia** → **Install and delete CIA**.
3. Return to the Home Menu and unwrap the **PkBank 3DS** gift icon.

### Custom Home Menu Icon / Banner (Optional)
Default Pearl White icon, banner, and chime audio are auto-generated by `scripts/gen_assets.py`.
To customize before running `make release`, replace:
- `meta/icon.png` (48×48 PNG)
- `meta/banner.png` (256×128 PNG)
- `meta/audio.wav` (16-bit PCM WAV, < 3 seconds)
